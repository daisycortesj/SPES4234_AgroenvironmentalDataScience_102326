# Data dictionary

⚠️ **All data in this folder are SIMULATED for teaching.** They were generated by [`make_data.py`](make_data.py) with a fixed random seed, so they are identical on every computer. Do not cite them as real results.

## `field_trial.csv` — main dataset (192 rows)
A maize nitrogen-rate × hybrid trial: 2 years × 2 sites × 3 blocks × 4 hybrids × 4 nitrogen rates.

| Column | Type | Units | Description |
|---|---|---|---|
| `plot_id` | text | — | Unique plot ID (P001–P192) |
| `year` | integer | — | 2024 or 2025 (2025 was simulated as a drier year) |
| `site` | text | — | `Upland` (drier) or `Bottomland` (wetter) |
| `block` | integer | — | Replicate block 1–3 |
| `variety` | text | — | Maize hybrid: `Hybrid_A`–`Hybrid_D` |
| `nitrogen_kg_ha` | integer | kg N/ha | Nitrogen fertilizer rate: 0, 60, 120, 180 |
| `soil_moisture_pct` | number | % (volumetric) | Mid-season soil moisture |
| `spad_chlorophyll` | number | SPAD units (unitless) | Leaf greenness meter reading. **3 missing** |
| `plant_height_cm` | number | cm | Final plant height |
| `days_to_flowering` | integer | days | Days from planting to silking |
| `grain_protein_pct` | number | % | Grain protein concentration |
| `yield_t_ha` | number | t/ha | Grain yield. **3 missing** (lost plots) |

**Built-in patterns to discover:** yield increases with N and plateaus; Bottomland yields more; 2025 yields are lower; SPAD rises with N similarly for all hybrids; Hybrid_D and Hybrid_B yield most.

## `growth_curves.csv` — weekly plant height (416 rows)
2025, block 1 plots only, measured every 7 days from 14 to 98 days after planting.

| Column | Units | Description |
|---|---|---|
| `plot_id`, `site`, `variety`, `nitrogen_kg_ha` | — | Same as above |
| `days_after_planting` | days | 14, 21, … 98 |
| `height_cm` | cm | Plant height on that date |

## `de_results.csv` — simulated differential expression (3,000 genes)
Format mimics DESeq2 output for a drought vs. control comparison. Gene symbols of a few well-known *Arabidopsis* drought-response genes (e.g., *RD29A*, *NCED3*, *DREB2A*) are attached to the top simulated genes so labels look familiar. **The statistics are invented.**

| Column | Description |
|---|---|
| `gene` | Gene ID or symbol |
| `baseMean` | Mean normalized read count |
| `log2FoldChange` | log₂(drought / control) |
| `pvalue` | Raw p-value |
| `padj` | Benjamini–Hochberg adjusted p-value |
